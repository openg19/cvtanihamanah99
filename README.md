# CV TANIH AMANAH99 — ERP Keuangan & Produksi (Cloud Sync + PWA Android/PC)

## Cara Mengaktifkan Sinkronisasi Otomatis di Semua Perangkat (HP Android & PC):
1. Ekstrak file `cv_tanih_amanah99_vercel.zip` dan unggah ke repositori GitHub lalu deploy ke **Vercel**.
2. Di dashboard proyek Vercel Anda, buka tab **Storage** → klik **Create Database** → pilih **Upstash Redis** (Gratis) → klik **Connect to Project**.
3. Lakukan **Redeploy** sekali saja di Vercel.
4. Selesai! Sekarang setiap kali Anda membuka domain Vercel Anda dari HP Android, PC, atau perangkat mana pun dan masuk dengan **Username & Kata Sandi yang sama**, seluruh data transaksi, hutang, piutang, kas, dan stok akan otomatis sinkron secara real-time.
