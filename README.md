# CV TANIH AMANAH99 — PWA (Siap Instal Android & PC via Vercel)

## Cara Pasang ke Vercel:
1. Ekstrak file `cv_tanih_amanah99_vercel.zip`.
2. Upload seluruh isinya (`index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`, `vercel.json`) ke GitHub lalu hubungkan ke Vercel (atau drag-and-drop via Vercel CLI).
3. Setelah domain Vercel aktif (HTTPS), buka di Chrome Android atau Chrome/Edge PC, lalu klik tombol **"📲 Instal App (Android/PC)"** di pojok kanan atas untuk menginstal langsung ke layar utama HP/Desktop.
